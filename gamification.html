01 · Gamification

Gamification ไม่ใช่แค่ Point, Badge, Leaderboard

ช่วงนี้เริ่มจากการเข้าใจว่า พฤติกรรมเกิดเพราะอะไร แล้วค่อยเลือกกลไกจากเกมให้เหมาะกับจังหวะที่คนยังไม่อยากเริ่ม ยังไม่ลงมือ หรือทำแล้วไม่รู้สึกคืบหน้า

Foundation

ก่อน Gamify ต้องเข้าใจ Behavior

อาจารย์เริ่มจาก Behavioral Science เพื่อเตือนว่าเวลา “คนไม่ทำ” อย่ารีบสรุปว่าเป็นเพราะเขาไม่อยากทำ เพราะพฤติกรรมถูกผลักทั้งจากตัวคนและสิ่งแวดล้อม

B = f(P,E)

พฤติกรรม = คน + สภาพแวดล้อม

ในคลาสใช้ภาพ “ความคิดของคน” อยู่ภายใน “สภาพแวดล้อม” เพื่อให้เห็นว่ากระบวนการ ระบบ เครื่องมือ หรือบรรยากาศรอบตัวสามารถช่วยหรือขวาง Behavior ได้

B = MAT

Motivation + Ability + Trigger

กรอบที่ใช้ในคลาสช่วยไล่ดูง่าย ๆ ว่า คนยังไม่ทำเพราะ ไม่อยาก, ทำไม่ไหว/ยากเกินไป หรือ ไม่มีตัวกระตุ้นในจังหวะที่เหมาะ

หลักคิดสำคัญของช่วงต้นคลาส: การจูงใจพฤติกรรมทำได้ 2 ทาง — ปรับที่คน และปรับที่สิ่งแวดล้อม ถ้าระบบยังฝืด การเพิ่ม Reward อย่างเดียวอาจไม่ช่วย
Intrinsic Motivation

Autonomy · Mastery · Purpose

ช่วงแรงจูงใจภายในชี้ให้เห็นว่า คนไม่ได้ขับเคลื่อนด้วยของรางวัลอย่างเดียว แต่ยังต้องรู้สึกว่า “ฉันเลือกได้ — ฉันเก่งขึ้น — สิ่งนี้มีความหมาย”

Autonomy

ได้กำหนดทางเลือกด้วยตัวเอง

เปิดพื้นที่ให้คนเลือกเส้นทาง วิธีทำ หรือลำดับบางอย่าง แทนการบังคับทุกขั้น

Mastery

เห็นว่าตัวเองพัฒนาขึ้น

Progress, Level, Skill และ Feedback ช่วยให้คนรู้ว่าตัวเองดีขึ้น ไม่ได้ทำไปแบบมองไม่เห็นปลายทาง

Purpose

เชื่อมกับสิ่งที่มีความหมาย

เมื่อกิจกรรมโยงกับเป้าหมายที่ใหญ่กว่าการ “ทำให้ครบ” คนมีเหตุผลที่จะทุ่มเทและทำต่อ

PBL → Beyond PBL

Point · Badge · Leaderboard เป็นเพียงจุดเริ่ม

สไลด์ PBL ใช้เป็นภาพเข้าใจง่าย แต่คลาสพาต่อไปถึง Level, Progress Bar, Rewards, Quest และ mechanics อื่น ๆ ที่ช่วยคนคนละจังหวะ

Point

ทำให้ Feedback จับต้องได้

ใช้เมื่ออยากสะท้อนว่าการกระทำบางอย่างมีคุณค่า หรืออยากให้เห็นความคืบหน้าแบบสะสม

Badge

ยืนยัน milestone หรือบทบาท

เหมาะกับการรับรองการมีส่วนร่วม ความสามารถ สถานะ หรือ achievement บางอย่าง

Leaderboard

ทำให้เห็นอันดับเทียบกับกลุ่ม

เหมาะกับบริบทที่การแข่งขันช่วยเพิ่มพลัง แต่ไม่จำเป็นต้องใช้ทุกระบบ เพราะบางงานควรเน้น collaboration มากกว่า

Level

ทำให้รู้สึกว่า “โตขึ้น”

เหมาะกับ journey ที่อยากให้คนเห็นขั้นของการพัฒนาและปลดล็อกสิ่งใหม่

Progress Bar

ทำให้เห็นว่าเหลืออีกเท่าไร

ลดความรู้สึกว่าเป้าหมายไกลเกินไป และช่วยให้คนอยากปิดงานให้จบ

Rewards

ตอบกลับการกระทำที่อยากเห็น

อาจเป็นสิทธิ์ การยอมรับ บทบาท หรือของรางวัล ขึ้นอยู่กับพฤติกรรมที่อยาก reinforce

Tool Map

เครื่องมือที่อาจารย์แชร์ — แต่ละอันใช้ยังไง

ไม่ต้องใส่ทุก mechanic พร้อมกัน ให้เลือกจากปัญหาที่กำลังเกิดจริง แล้วใช้เครื่องมือเท่าที่จำเป็น

เครื่องมือ
ใช้เมื่อ...
วิธีใช้ในงาน
SignpostMotivation
คนไม่รู้ว่าต้องเริ่มตรงไหน หรือ journey มีหลายขั้น
ทำ next step ให้ชัด เช่น “เริ่มภารกิจแรก”, “เหลืออีก 2 ขั้น”, “ทำต่อที่นี่”
Surprise & CuriosityMotivation
อยากดึงความสนใจและทำให้กลับมาเปิดดูต่อ
ใช้ teaser, unlock, mystery content หรือ reveal บางอย่างเมื่อทำสำเร็จ
Story & NarrativeMotivation
กิจกรรมดูเป็น task แยก ๆ และไม่มีความหมายร่วม
ผูกหลายกิจกรรมเป็นเรื่องเดียว เช่น mission, season หรือ storyline
Countdown TimerMotivation
ต้องการสร้างจังหวะหรือ deadline ที่ชัด
ใช้กับรอบสมัคร ภารกิจระยะสั้น หรือ challenge ที่มีช่วงเวลา
Branching ChoiceAction
อยากให้คนมีทางเลือกและรู้สึกเป็นเจ้าของ
ให้เลือกเส้นทางเรียน เลือก quest หรือเลือกวิธีทำภารกิจ
Collect & TradeAction
ระบบมี item/resource ที่สะสมและแลกเปลี่ยนได้
ใช้ token, card, stamp หรือ resource ที่คนสะสมเพื่อนำไปแลก/ต่อยอด
Competition / PvPAction
กลุ่มสนุกกับการแข่งขันและกติกาชัด
แข่งแบบทีม รอบสั้น หรือ challenge เฉพาะกิจ ไม่จำเป็นต้องเป็น ranking ถาวร
Customization / AvatarAction
อยากเพิ่ม sense of ownership
ให้เลือก avatar, theme, path, badge set หรือรูปแบบการเข้าร่วม
Team / High FiveAction
ต้องการ collaboration มากกว่าการแข่งคนเดียว
ออกแบบ team mission, peer recognition หรือการช่วยกันปิด challenge
Mission / Quest / ChallengeAction
เป้าหมายใหญ่เกินไปจนไม่รู้จะเริ่มยังไง
แตกเป้าหมายเป็นภารกิจเล็กที่รู้ว่า “ทำอะไรแล้วถือว่าสำเร็จ”
Mini / Daily / Weekly QuestAction
อยากสร้างความต่อเนื่อง
กำหนด cadence ให้ behavior เกิดซ้ำแบบเล็ก ๆ แทนการรอ event ใหญ่
Point / XP / Skill PointFeedback
อยากให้คนเห็นค่าหรือพัฒนาการของการกระทำ
ให้คะแนนกับ behavior ที่มีความหมาย และแยก skill point ตามประเภทได้
Badge / CertificateFeedback
มี milestone หรือ contribution ที่ควรได้รับการยอมรับ
ใช้ badge ตามบทบาท skill หรือ milestone ไม่ใช่แจกทุกอย่างจนหมดความหมาย
Leaderboard / RankingFeedback
ต้องการ social comparison
ใช้ leaderboard แบบทีม/รอบเวลา หรือหลายมิติ เพื่อลดการกดคนท้ายตาราง
Level / Progress / StreakFeedback
อยากให้รู้ว่า “ไปถึงไหนแล้ว”
แสดง progress ที่ชัด และให้ level สอดคล้องกับความสามารถ/การมีส่วนร่วมจริง
Rewards — SAPS

รางวัลไม่จำเป็นต้องเป็น “ของ”

สไลด์ SAPS ช่วยขยายมุมคิดว่ารางวัลอาจเป็นการยอมรับ สิทธิ์ บทบาท หรือของจริงก็ได้

Status

สถานะ / การยอมรับ

เช่น VIP, Expert, Champion, Public Recognition

Access

สิทธิ์เข้าถึง

เช่น ข้อมูลก่อนใคร ห้องพิเศษ โอกาสเข้าร่วมบางกิจกรรม

Power

สิทธิ์หรืออำนาจบางอย่าง

เช่น โหวต ตัดสินใจ ช่วยกำหนดทิศทาง หรือมีสิทธิ์พิเศษเหนือระบบ

Stuff

สิ่งของ / เงิน / ส่วนลด

ใช้ได้ แต่ไม่จำเป็นต้องเป็นคำตอบแรกเสมอไป

มุมที่น่าสนใจจากคลาส: Leaderboard กับ Gifting / Sharing อยู่ร่วมกันได้ แปลว่า Gamification ไม่ได้เท่ากับการแข่งขันอย่างเดียว
Apply

เอาไปใช้กับงาน HR / Learning / Engagement

เริ่มจาก Behavior ที่อยากเห็น แล้วเลือก mechanic ตามหน้าที่ ไม่ใช่เริ่มจาก “อยากมีแต้ม”

อยากให้สมัคร/เริ่มเรียน

Signpost + Story + Quest ทำให้จุดเริ่มชัดและเห็นเหตุผลที่น่าเข้าร่วม

อยากให้เรียนต่อเนื่อง

Mini Quest + Progress Bar + Streak + Level ทำให้เห็นความคืบหน้าและกลับมาทำต่อ

อยากให้แชร์ความรู้

Team + High Five + Karma/Point + Badge + Status ช่วยให้การช่วยกันได้รับการมองเห็น

อยากให้เห็นพัฒนา

Skill Point + Level + Milestone + Feedback ทำให้คนเห็นว่าตัวเองเก่งขึ้นตรงไหน

อยากให้ระบบมีความหมาย

เติม Autonomy, Mastery, Purpose เข้าไป อย่าให้ระบบเหลือแค่ “ทำเพื่อแต้ม”

คำถามก่อนออกแบบ: ตอนนี้คนติดที่ Motivation, Action หรือ Feedback? — ตอบให้ได้ก่อน แล้วค่อยเลือก mechanic
