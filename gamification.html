01 · Gamification

Gamification ไม่ใช่แค่ Point, Badge, Leaderboard

แก่นของช่วงนี้คือการเข้าใจก่อนว่า พฤติกรรมเกิดเพราะอะไร แล้วค่อยเลือกกลไกจากเกมมาช่วยให้คนสนใจ ลงมือทำ เห็นความก้าวหน้า และอยากกลับมาทำต่อ

Behavioral SciencePBL & Beyondเครื่องมือRewardนำไปใช้
Foundation

ก่อน Gamify ต้องเข้าใจ Behavior

อาจารย์เริ่มจาก Behavioral Science เพราะถ้าคนไม่ทำสิ่งที่เราอยากให้ทำ คำตอบไม่ได้มีแค่ “เขาไม่อยากทำ” แต่อาจอยู่ที่ตัวคน วิธีคิด ความสามารถ หรือสภาพแวดล้อมรอบตัว

B = f(P,E)

พฤติกรรมเกิดจากคน + สภาพแวดล้อม

ในคลาสใช้ภาพให้เห็นว่า Behavior ไม่ได้อยู่ในหัวคนอย่างเดียว สิ่งแวดล้อมรอบตัวสามารถผลักหรือขัดพฤติกรรมได้

เวลาใช้: ถ้าอยากเปลี่ยนพฤติกรรม อย่ารีบสรุปว่าเป็นปัญหา Motivation ให้เช็ก Process และ Environment ด้วย
B = MAT

Motivation + Ability + Trigger

กรอบที่อาจารย์ใช้ในคลาสชี้ว่า ต่อให้คนอยากทำ แต่ถ้าทำยากเกินไป หรือไม่มี Trigger ในจังหวะที่เหมาะ พฤติกรรมก็อาจไม่เกิด

เวลาใช้: ใช้ไล่ดูว่าปัญหาอยู่ที่ “ไม่อยาก / ทำไม่ได้ / ไม่มีตัวกระตุ้น” ก่อนออกแบบกิจกรรม
หลักคิดที่อาจารย์ย้ำ: การจูงใจพฤติกรรมทำได้ทั้งการปรับที่ “คน” และการปรับ “สิ่งแวดล้อม” ถ้า Process ยังฝืด การเพิ่มรางวัลอย่างเดียวมักไม่พอ

แรงจูงใจภายใน: Autonomy · Mastery · Purpose

Autonomy

มีทางเลือกของตัวเอง

คนมีแรงทำมากขึ้นเมื่อรู้สึกว่าตัวเองมีสิทธิเลือกวิธีหรือเส้นทาง ไม่ถูกบังคับทุกขั้น

Mastery

รู้สึกว่าตัวเองเก่งขึ้น

ความคืบหน้าและการพัฒนาความสามารถทำให้คนอยากทำต่อ มากกว่าทำแล้วไม่รู้ว่าตัวเองดีขึ้นไหม

Purpose

เห็นความหมายที่ใหญ่กว่าตัวเอง

ถ้าคนรู้ว่าสิ่งที่ทำเชื่อมกับเป้าหมายที่มีความหมาย เขาจะทุ่มเทได้มากกว่างานที่ทำเพื่อจบ ๆ ไป

PBL → Beyond PBL

แต้ม เหรียญ อันดับ เป็นแค่ชั้นแรก

PBL ช่วยให้เข้าใจ Gamification ได้ง่าย แต่ถ้าออกแบบจริง ยังมีเครื่องมืออีกหลายแบบที่ช่วยคนคนละจังหวะ

Point

ทำให้ Feedback จับต้องได้

ใช้เมื่ออยากให้คนรู้ว่าการกระทำบางอย่างมีคุณค่า หรือสะสมความคืบหน้าได้

Badge

ยืนยันความสำเร็จหรือสถานะ

เหมาะกับ milestone, skill, role หรือการยอมรับบางประเภท

Leaderboard

ทำให้เห็นตำแหน่งเทียบกับคนอื่น

เหมาะกับกลุ่มที่ชอบการแข่งขัน แต่ต้องระวังไม่ให้คนท้ายตารางรู้สึกหมดแรง

Beyond PBL ที่อาจารย์ยกขึ้นมา: Level · Progress Bar · Rewards และเมื่อนำไปออกแบบระบบจริง ยังเชื่อมต่อกับ Quest, Story, Team, Choice, Streak และ Feedback ได้อีก
Tool Map

เครื่องมือ Gamification ที่อาจารย์แชร์

สไลด์รวมเครื่องมือแบ่งเป็น 3 ชั้นใหญ่ ๆ คือ Motivation → Action → Feedback วิธีเลือกง่ายที่สุดคือดูว่าตอนนี้คน “ยังไม่อยากเริ่ม”, “ยังไม่ลงมือ” หรือ “ทำแล้วไม่รู้สึกคืบหน้า”

Motivation

ใช้ดึงความสนใจ ทำให้อยากเริ่ม และรู้ว่ากำลังจะเจออะไร

Signpostบอกทิศทางหรือ next step ให้ชัด เหมาะกับ journey ที่มีหลายขั้น
Surprise & Curiosityสร้างความอยากรู้ด้วย surprise, teaser หรือการ unlock
Story & Narrativeผูก task หลายชิ้นให้เป็นเรื่องเดียว ทำให้กิจกรรมมีความหมาย
Countdown Timerสร้างจังหวะและ urgency เมื่อมีเวลาหรือรอบกิจกรรมจำกัด

Action

ใช้กำหนดว่าคนจะ “ทำอะไร” ในระบบ

Branching Choiceให้เลือกเส้นทางหรือวิธีทำ เพิ่มความรู้สึกมีอิสระ
Collect & Tradeสะสมและแลกเปลี่ยน เหมาะกับระบบที่มี item หรือ resource
Competition / PvPใช้พลังการแข่งขันเมื่อกลุ่มและกติกาเหมาะ
Customization / Avatarเปิดให้คนปรับสิ่งต่าง ๆ ให้เป็นของตัวเอง
Team / High Fiveออกแบบให้คนช่วยกัน ไม่จำเป็นต้องแข่งขันทุกอย่าง
Mission / Quest / Challengeเปลี่ยนเป้าหมายใหญ่ให้เป็นภารกิจที่เริ่มทำได้
Boss Battle / Side Questใช้สร้าง milestone ใหญ่และภารกิจเสริม
Mini / Daily / Weekly / Monthly Questกำหนด cadence ให้พฤติกรรมเกิดซ้ำในจังหวะที่ต้องการ

Feedback

ใช้ตอบกลับให้คนรู้ว่า “ทำแล้วเกิดอะไรขึ้น”

Point / XP / Skill Point / Karmaสะท้อนค่าของการกระทำหรือความคืบหน้า
Badge / Certificateยืนยัน milestone, ความสามารถ หรือ contribution
Leaderboard / Rankingทำให้เห็นตำแหน่งหรือความสำเร็จเทียบกับกลุ่ม
Levelทำให้เห็นว่า “โตขึ้น” จากจุดเดิมอย่างไร
Progress Bar / Streakช่วยให้คนเห็นว่าเหลืออีกเท่าไรและต่อเนื่องแค่ไหน
Rewards / Status / Access / Powerให้สิ่งตอบแทนหรือสิทธิที่สะท้อน contribution
Rewards

Reward ไม่จำเป็นต้องเป็นของ

ช่วง SAPS ช่วยให้คิดกว้างกว่า “แจกของรางวัล” เพราะบางครั้งสิ่งที่คนให้คุณค่าคือการได้รับการยอมรับ สิทธิพิเศษ หรือบทบาทที่มากขึ้น

SAPS

Status · Access · Power · Stuff

Status เช่น VIP/การยอมรับ · Access สิทธิ์เข้าถึงข้อมูลหรือโอกาสพิเศษ · Power สิทธิ์ช่วยตัดสินใจ/บทบาทพิเศษ · Stuff เงิน ของ ส่วนลด โปรโมชั่น

Design Tip

ให้ Reward ตามคุณค่าที่อยาก reinforce

ถ้าอยากได้การแชร์ความรู้ อาจให้ Status หรือ Special Role มากกว่าของ ถ้าอยากให้กลับมาทำต่อ อาจใช้ Progress + Milestone มากกว่ารางวัลปลายทางอย่างเดียว

ตัวอย่างจากคลาส: Leaderboard และ Gifting / Sharing สามารถอยู่ในระบบเดียวกันได้ แปลว่า Gamification ไม่ได้แปลว่าทุกคนต้องแข่งกันเสมอ
Apply

เวลาเอาไปใช้กับงาน เริ่มอย่างไร

อย่าเริ่มจากคำถามว่า “จะใส่แต้มกี่แต้ม” ให้เริ่มจากพฤติกรรม แล้วค่อยเลือก mechanic ที่ทำหน้าที่ตรงจุด

อยากให้เริ่ม

ใช้ Signpost, Curiosity, Story หรือ Quest เพื่อทำให้จุดเริ่มชัดและน่าสนใจ

อยากให้ทำต่อ

ใช้ Progress Bar, Level, Streak, Mini Quest หรือ Daily/Weekly Quest

อยากให้ช่วยกัน

ใช้ Team, High Five, Sharing, Karma Point, Badge หรือ Special Role

อยากให้เห็นพัฒนา

ใช้ XP, Skill Point, Level, Milestone และ Feedback ที่บอกว่าเก่งขึ้นตรงไหน

อยากให้รู้สึกมีความหมาย

เชื่อม Autonomy, Mastery, Purpose เข้ากับระบบ ไม่ใช่ให้ Reward อย่างเดียว
